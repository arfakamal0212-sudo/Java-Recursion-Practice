# Java Recursion Practice

This repository contains Java recursion programs covering fundamental recursive algorithms and placement-oriented coding practice.

## Programs Included

### Basic Recursion Programs

1. Recursive Factorial
2. Recursive Fibonacci
3. Recursive Sum of N Numbers
4. Recursive Power
5. Recursive Reverse Number
6. Recursive GCD (Greatest Common Divisor)
7. Recursive Decimal to Binary

## Concepts Covered

* Recursion Basics
* Base Case
* Recursive Calls
* Call Stack
* Mathematical Recursion
* Number Manipulation using Recursion
* Divide and Conquer Approach
* Recursive Problem Solving
